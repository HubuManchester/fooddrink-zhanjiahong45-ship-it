# NutriBite

NutriBite is a .NET MAUI Food and Drink coursework app. It records meals and drinks, shows nutrition summaries, and demonstrates mobile hardware features for the assessment screencast.

Open `FoodDrinkApp.sln` in Visual Studio 2022 with the .NET MAUI workload installed, or build from the command line:

```powershell
dotnet build .\FoodDrinkApp\FoodDrinkApp.csproj -f net9.0-android
dotnet test
```
